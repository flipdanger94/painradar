# Фазы и состав поставки

Код подготовлен по функциональным областям ТЗ. Проверки выполнялись при контрольных точках и консолидированно перед упаковкой; нет утверждения, что полный комплект test/typecheck/lint/build запускался после каждой из десяти фаз.

| Фаза | Состав                                             | Статус                                                   |
| ---- | -------------------------------------------------- | -------------------------------------------------------- |
| 1    | Architecture, schema, migrations, auth, UI shell   | Код реализован; живой auth не проверен                   |
| 2    | SourceAdapter, HN/GitHub/Reddit ingestion          | Paged collector/checkpoints/backfill config реализованы; живые source credentials/scopes нужны          |
| 3    | Cached embeddings, dedup, semantic clustering      | Код реализован; calibration/scale limits в README        |
| 4    | Score/confidence/growth, trending                  | Реализовано; тесты пройдены                              |
| 5    | Details, source evidence, competitor research/gap, MVP | Код реализован; provider calls не выполнялись            |
| 6    | Search, filters, watchlist, export                 | Реализовано; hybrid candidate union                      |
| 7    | Radars, notifications, alerts                      | Реализовано in-app/email и outbound signed webhook queue    |
| 8    | Plans, Stripe checkout/portal/webhooks/invoices    | Код реализован включая Agency; живой Stripe не проверен                            |
| 9    | Admin, PostHog, Sentry                             | События подключены; финансовые metrics остаются estimate |
| 10   | Tests, CI, production build, deploy                | Проверки кода пройдены; browser/live/deploy не выполнены |

## Миграции

0000–0003 сохранены из первой поставки. Новые миграции 0004–0005 добавляют tenant schema, 0006 — permissions/quotas/invites, 0007 — atomic delivery claims/report outbox; 0008 — collection state; 0009 — keyset index; 0010 — publication queue/cursors; 0011 — atomic snapshots, claims и paged alert processing; 0012 — billing baseline/history schema; 0013 — fenced subscription sync и observed cohort metrics; 0014 — reconciliation leases/history IDs; 0015 — shared observation commit, canonical Customer registration и bounded reconciliation claims/backoff; 0016 — canonical industry taxonomy/matching и radar publication compatibility; 0017–0018 — opt-in data maintenance schema/functions, retention indexes и retired evidence guards; 0019 — fresh invoice synchronization/generation fence и provider observation dates; 0020 — bounded paged invoice recovery, persisted checkpoints и shared leased observations. Применяйте через npm run db:migrate в порядке journal. На существующей базе уже применённые миграции не переписываются.
